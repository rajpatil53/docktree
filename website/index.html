Parallel agents, unblocked

Every agent.
Its own stack.

AI agents can work across Git worktrees in parallel. Local dev cannot—until now. Docktree gives every worktree an isolated Docker Compose stack, so ports don’t collide and databases don’t bleed between tasks.
